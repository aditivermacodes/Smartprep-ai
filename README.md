# SmartPrep AI 🚀

SmartPrep AI is a MERN stack AI-powered interview preparation platform that helps users:

- Upload resumes
- Generate AI-based interview questions
- Practice technical & HR interviews
- View previous interview history

---

# Tech Stack

## Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Multer
- PDF Parse

## AI Integration
- OpenRouter API
- DeepSeek AI Model

---

# Features

✅ User Authentication

✅ AI Interview Question Generation
